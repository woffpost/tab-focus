# Tab Focus

Chrome-расширение: называешь тему, вкладки по ней собираются в цветную группу, остальные сворачиваются в «Не по теме». Заголовки вкладок обрабатываются локальной моделью и не покидают браузер.

## Запуск

```
npm install
npm run build
```

`chrome://extensions` → режим разработчика → «Загрузить распакованное» → папка `dist`. При первом включении фокуса скачивается модель (около 120 МБ).

## Проверки

- `npm test` — логика решений
- `npm run e2e` — расширение в настоящем Chromium с настоящей моделью
- `npm run eval` — точность моделей на размеченных вкладках из `eval/cases.json`
